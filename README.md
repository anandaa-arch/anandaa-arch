## 🔬 Research & Featured Projects

### [AEGIS — Edge-Native AI Firewall](https://github.com/anandaa-arch)
`Phi-3 SLM` `YOLOv8` `TypeScript` `Python` `Edge AI`
> 🏆 **Finalist — IIT Delhi Sprint4Good Hackathon (200+ teams)**

An edge-native cognitive firewall that intercepts adversarial LLM inputs before they reach the model. Uses a fine-tuned Phi-3 small language model for prompt threat classification and YOLOv8 for visual PII detection — running entirely on-device in **<500ms**, with zero cloud round-trips for absolute zero-trust data sovereignty.

### [ACO-QEC: Swarm-Powered Quantum Error Correction](https://github.com/anandaa-arch)
`Python` `Qiskit Aer` `Ant Colony Optimization` `Simulation`
> 📄 **Independent Research — MMCOE (Guide: Dr. Manisha Dhage)**

First known application of Ant Colony Optimization to QEC strategy selection. Designed an adaptive controller that dynamically selects between Repetition, Steane, and Shor error correction codes based on real-time noise conditions. Achieved **15–25% logical error reduction** vs. static baselines, adapting within 2–3 epochs.
